Privacy policy — Review this! (Design review extension)

Last updated: 24 April 2026

This extension adds pins and threaded comments on websites allowed by the permissions you approve at install (apps on herokuapp.com). This policy explains what information is processed and where it is stored.

Data on your device

The extension uses Chrome local storage (chrome.storage.local) to save: your optional profile (display name and email you enter in the product), comments and pin data, and settings needed to show the UI. That data remains on your device unless optional cloud sync is enabled in the build you use.

Optional cloud sync

If the publisher ships the extension with a Supabase project configured, the extension sends and loads review data over HTTPS to that project: typically the page identifier (origin, path and query of the URL you are reviewing) and comment threads including the display name shown on each comment. Email from your profile is stored locally for attribution and possible future notifications; it is not uploaded to Supabase in the current version.

Who is responsible

The organisation that publishes the extension and operates any configured backend decides retention, access rules, and security for synced data. The extension does not sell personal information and does not include third-party advertising or analytics.

Permissions

Host access is limited to the origins declared in the manifest so the content script can run on pages you review. The scripting permission is used only to inject the extension’s own scripts when you use the toolbar action, as described in the store listing.

Your choices

You can remove the extension to delete its locally stored data from that browser profile. For data held in a team Supabase project, contact the publisher for access or deletion requests.
